# Contributing to Zero2AI

Thank you for considering contributing! Please follow the steps below.

## Development Workflow

1. Fork the repo and create a feature branch.
2. Install dependencies with `make deps` (or use Docker: `make docker-build`).
3. Run `make test` to ensure all tests pass.
4. Submit a pull request with a clear description and checklist.

## Code Style

- Python >= 3.12
- Formatting: ruff + black
- Lint: ruff
- Tests: pytest

## Commit Messages

- Use Conventional Commits (feat, fix, docs, chore, refactor, test, build).

## Reporting Issues

- Use the issue template. Provide steps to reproduce and environment details.

## Community

- See `docs/community/README.md` and join the community call.
